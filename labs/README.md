pairs lesson concepts with a hands-on practice repo. The notes tell you what to
teach, the mistakes learners usually make, and what to demo live.

## How to run a session

1. Open the matching cheat sheet from [`../cheat-sheets/`](../cheat-sheets/)
   alongside the module.
2. Teach the concepts, then demo live in the practice repo.
3. Set the learners loose on the practice repo exercises.
4. Close with the relevant practice questions from
   [`../practice-questions/`](../practice-questions/).

All sessions use British English and avoid em and en dashes.
